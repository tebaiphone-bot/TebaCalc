# TebaCalc 3D

Calculadora de costos de impresión 3D (filamento) para Android.

- `app.html`: la app completa (HTML, CSS y JS sin dependencias). Se publica tal cual como vista previa web.
- `npm run build`: genera `www/index.html` para empaquetar con Capacitor.
- `.github/workflows/apk.yml`: GitHub Actions compila el APK en cada push y lo deja como artefacto descargable ("TebaCalc-apk").

Diseño acordado: ver el documento "TebaCalc 2.0 – Diseño".
